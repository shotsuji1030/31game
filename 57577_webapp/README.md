# 57577 Webアプリ

## 起動方法

Python 3.10以上を用意し、フォルダ内で以下を実行します。

```bash
pip install -r requirements.txt
streamlit run app.py
```

## カードの追加
`57577_cards.xlsx` の「5音カード」「7音カード」シートの「テキスト」列に追加してください。変更後はアプリを再起動するか、Streamlitのキャッシュをクリアしてください。音数の自動検査はありません。

## 公開
1. このフォルダの `app.py`、`57577_cards.xlsx`、`requirements.txt` をGitHubリポジトリにアップロードします。
2. Streamlit Community CloudでGitHubリポジトリと `app.py` を選択し、デプロイします。
3. 発行されたURLを共有すると、各ユーザーが自分の端末で**個別の1人用ゲーム**を遊べます。

## 現在の仕様
- 5音2枚、7音3枚の手札をランダム配布
- 場の5音3枚、7音5枚と交換（同音数のみ）
- 1ラウンド最大3回、全2ラウンド
- 交換後の手札カードはゲームから除外、場の欠員は次ラウンド開始時に山札から補充
- 短歌をテキスト保存

**オンラインで同じルームに参加するマルチプレイ、投票、ログインは未実装です。**
